# Solo Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow a single player to start and play a game alone by lifting the 2-player minimum.

**Architecture:** Two small guard changes — one on the server (`start_game` handler) and one in the client lobby (`canStart` threshold + "waiting" message visibility). No new files, no new events, no new screens.

**Tech Stack:** Node.js + Socket.io (server), React + Vite (client)

---

### Task 1: Lift the server-side 2-player minimum

**Files:**
- Modify: `server/server.js:140-141`

- [ ] **Step 1: Change the guard from `< 2` to `< 1`**

In `server/server.js`, find:

```js
if (room.players.filter(p => p.connected).length < 2)
  return ack?.({ ok: false, error: 'Need at least 2 players.' });
```

Replace with:

```js
if (room.players.filter(p => p.connected).length < 1)
  return ack?.({ ok: false, error: 'Need at least 1 player.' });
```


Expected: all tests pass (no test covers the 2-player guard, so nothing should break).

### Task 2: Update the lobby client

**Files:**
- Modify: `client/src/pages/Lobby.jsx:17,51-53`

- [ ] **Step 1: Change `canStart` threshold and remove the solo waiting message**

In `client/src/pages/Lobby.jsx`, find:

```js
const connectedCount = room.players.length;
const canStart       = isHost && connectedCount >= 2;
```

Replace with:

```js
const connectedCount = room.players.length;
const canStart       = isHost && connectedCount >= 1;
```

Then find and **delete** this block entirely (the host is always present, so `connectedCount` is always ≥ 1, making this message unreachable and misleading for solo play):

```jsx
{connectedCount < 2 && (
  <p className="waiting-msg">Waiting for at least one more player…</p>
)}
```

- [ ] **Step 2: Verify the button label**

The button already reads `{canStart ? 'Start Game' : 'Waiting for players…'}`. With `canStart` now true for a solo host, the button will correctly show "Start Game" with no further changes needed. No action required.
